# Withdrawal notice: v0.0.2

- Version: 0.0.2
- Publication state at withdrawal: incomplete
- Staged ledger event digest: `ab1207957e717117cdbc953011ca747630f41127e53359fff2eb7cbf79c06d05`
- Affected channels: the source release archives and, where staging reached them, the GitHub CLI extension release and the Homebrew tap staging branch

## Reason

Non-production release rehearsal. This version carries no OrgTop behavior and was never intended for use; install v0.1.0 or later.

## What was withdrawn

The v0.0.2 releases and tags were deleted from
`fmueller/orgtop` and `fmueller/gh-orgtop`, and the
`Formula/orgtop.rb` formula in `fmueller/homebrew-tap` no longer selects this
version.

## What cannot be withdrawn

Executables already downloaded, package and build caches holding them, published
checksums, and issued build attestations for v0.0.2 cannot be revoked. A host
that installed v0.0.2 before this notice keeps running it until it upgrades.

## Reuse

Version 0.0.2 may only be staged again at the identical source commit with all twelve original artifact digests. Different bytes require a new semantic version.
