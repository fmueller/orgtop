# Withdrawal notice: v0.0.1

- Version: 0.0.1
- Publication state at withdrawal: incomplete
- Staged ledger event digest: `f04acd03c8478afe4e8072b0e9123f762fffc2de1532bf50864fba19850b2303`
- Affected channels: the source release archives and, where staging reached them, the GitHub CLI extension release and the Homebrew tap staging branch

## Reason

Distribution rehearsal only, not a product release.

## What was withdrawn

The v0.0.1 releases and tags were deleted from
`fmueller/orgtop` and `fmueller/gh-orgtop`, and the
`Formula/orgtop.rb` formula in `fmueller/homebrew-tap` no longer selects this
version.

## What cannot be withdrawn

Executables already downloaded, package and build caches holding them, published
checksums, and issued build attestations for v0.0.1 cannot be revoked. A host
that installed v0.0.1 before this notice keeps running it until it upgrades.

## Reuse

Version 0.0.1 may only be staged again at the identical source commit with all twelve original artifact digests. Different bytes require a new semantic version.
