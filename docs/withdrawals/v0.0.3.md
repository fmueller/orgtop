# Withdrawal notice: v0.0.3

- Version: 0.0.3
- Publication state at withdrawal: completed
- Staged ledger event digest: `e342da19efbd84a99da2306e0092b5f99977638ae7506b0b7970f378431bb469`
- Affected channels: the source release archives, the GitHub CLI extension release, and the Homebrew tap formula

## Reason

Release-path rehearsal only. This version carries no OrgTop behavior and was withdrawn as soon as its rehearsal was verified.

## What was withdrawn

The v0.0.3 releases and tags were deleted from
`fmueller/orgtop` and `fmueller/gh-orgtop`, and the
`Formula/orgtop.rb` formula in `fmueller/homebrew-tap` no longer selects this
version.

## What cannot be withdrawn

Executables already downloaded, package and build caches holding them, published
checksums, and issued build attestations for v0.0.3 cannot be revoked. A host
that installed v0.0.3 before this notice keeps running it until it upgrades.

## Reuse

Version 0.0.3 is permanently reserved. A fix ships under a later semantic version.
